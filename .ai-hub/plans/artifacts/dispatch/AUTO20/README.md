# AUTO20 执行协议 —— 单会话串行自动执行 20 任务（编排者自治流水线）

> 用户授权（2026-09-21）：编排者在单会话内派**单个**执行者子 agent（独立上下文），auto 执行 20 个 task 不中断；保持 C-01 验收规则、批判纪律、盲测队列更新；每满 20 个向用户汇报。

## 一、流水线循环（每任务一轮回）

```
① 取队：从 queue.md 取最前 pending 任务（用户门控项跳过不停轮）
② 派发：单 agent（run_in_background），自包含 prompt（开工令全文+锚点+铁律）
③ 验收（C-01）：完工报告不采信，逐断言独立复现（跑测试/curl/git log/DB 只读参数化查询）
   ├─ PASS → ④；├─ FAIL → 写 REWORK 令重派（同任务最多 2 轮，超限挂起继续下一任务并记录）
   └─ agent 死亡/配额 → 编排者亲执行 → 报告交下一单 agent 反向审核（既定规则）
④ 批判登记：本单发现的 P0-P2 与教训 → 追加 critique-backlog-tracker.md
⑤ 盲测入队：按完成功能生成盲测场景 → 追加 blind-test-queue.md（status=pending）
⑥ 更新 queue.md（status/SHA/验收证据/批判项）+ git 三处 ref 校验（事故#2 戒律）
⑦ 立即取下一任务（不请示不停轮）；用户门控项（UAT/审批）挪 user-gate 清单
```

## 二、纪律继承（全部生效，逐字不变）

1. **C-01**：独立实证验收，不采信完工报告；验收断言逐个复现
2. **批判**：每单完工批判登记；90% 翻车在验收偷懒——只信报告或只走形式
3. **盲测**：盲测标准=最短但最不可妥协的一条；盲测队列随任务完成滚动更新并定期执行
4. **串行单 agent**：一次只派一个（防限速熔断，既定裁定）
5. **安全硬约束**（每单 prompt 内置）：凭据只走环境变量禁硬编码；服务端发 URL 请求仅 http/https+host 校验+拒绝环回/私有地址；SQL 一律参数绑定；API key 禁入报告/日志/commit
6. **git**：执行者单 commit 禁 push；编排者验收前后 `git rev-parse HEAD` 三处校验；取件按 SHA 不按分支名
7. **数据**：任何 DB 订正走三核闸（备份+行数一致+幂等）；只读复核一律参数化查询
8. **汇报**：每满 20 个验证通过的任务向用户汇报一次；中途被用户门控卡住的项挂起记录，不阻塞流水线

## 三、文件面

| 文件 | 用途 |
|---|---|
| `queue.md` | 20 任务队列（唯一事实源：状态/执行者/验收证据/批判项/SHA） |
| `blind-test-queue.md` | 盲测场景队列（随任务完成滚动追加，status 字段驱动） |
| `user-gate.md` | 需用户在线/审批的项（UAT、风格裁定、push 批准等） |
| 既有 kickoff 文件 | 各任务开工令（TO-EXEC-*/REWORK-* 全文即 agent prompt 主体） |

## 四、中断与恢复

- 任何单任务连续 2 轮返工不过 → 挂起该任务，流水线继续，20 报告时列出待用户裁
- 会话中断恢复：queue.md 的 status 字段即断点（running=重派该任务）；已完成任务的 SHA 链可审计
- 与外部并行作业冲突（ref 竞态）：派发前后 SHA 对账，不符即停轮上报
