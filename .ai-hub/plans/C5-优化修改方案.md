## 实施顺序与依赖

1. **先做 C5-2（形态断言门）**：纯脚本增量、零依赖，直接消除最高风险人因事故；
2. **再做 C5-1 doctor + C5-4① security-check**：两者都是"一条命令自检"，与 C5-2 共用 .env 读取/断言基建；
3. **然后 C5-3 进程治理**：涉及 stop 行为变化（优雅关闭窗口会让 stop 变慢约 10s），建议独立 commit 并更新 README §5 三命令说明；
4. **C5-5 归 C 阶段全量排期**（本批仅落附录横幅+对照表，半天内）。
