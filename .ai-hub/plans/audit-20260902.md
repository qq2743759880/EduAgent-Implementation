### 1.2 跳转逻辑断裂点（用户痛点"跳转混乱"的实锤）

1. **课程动线完全断裂**：courses.html:583 课程卡 `role=button` 无 href 无 click；course-detail.html:748-749 id 提取正则匹配不到自身路径，**恒回退 sid="1001"**；learning.html 全站 0 入口。
2. **死链**：admin-courses.html:482 `href="/admin/courses/${s.id}"` 指向 React 路由，静态站 404（且是"列表→课程详情"唯一出口）。
3. **孤立页**：course-detail / learning / admin-course-detail / admin-question-detail 全站无有效入站链接。
4. **无登出**：全站无退出按钮、无 `store.clear()` 调用；login-register 无 `?redirect=` 回跳实现（文案宣称有）。
5. **管理端无角色守卫**：admin-*.html 仅改文案提示，不校验 role 不重定向；admin-questions 连提示都没有。
6. **未登录行为不一致**：chat.html 强制跳登录，其余页静默降级演示数据。

### 1.3 edu-api.js 壳客户端缺陷

- L33-43：401 分支条件过窄（要求 `code` 为字符串）；非 JSON 错误响应 `return null` 被当成功——**全站鉴权兜底最大漏洞**。
- L7：BASE 硬编码 `http://127.0.0.1:8000`，换环境即断；无超时；401 跳转不带回跳参数；无 logout 便捷方法。

## 2. 后端路由面审计（edu-agent/app，main.py:342-405）

路由规模 ≈193 条，按域：auth/users、courses(C端)、study/progress/enrollments、practice(quiz/vocab/coding/math)、community、chat(SSE)、gamification、recommend/mindmap/memory、market/trade/after_sales、admin(course/question/user/rag)、mcp、knowledge、health/metrics。

| # | 问题 | 证据 |
|---|---|---|
| B1 | `POST /api/gamification/me/award` 任意登录用户可给自己加积分（delta≤100000，无角色校验） | gamification/router.py:29-41 |

### 2.2 P1 缺陷

- DEBUG 双后门（X-Force-Role / 无 Token 虚拟管理员），生产仅靠 `DEBUG=False` 单点关闭（auth/dependencies.py:80-127）——**部署前必须 DEBUG=False**（AGENTS.md 教训⑥）。
- `/api/metrics/cache-context-dashboard|otel|trace/*` 完全无鉴权（monitoring/router.py:23,40,55）。
- `/api/memory/admin/dream/run` 前缀未进 AdminAuthMiddleware.ADMIN_PREFIXES（分层不一致）。
- 错误码 `"40021"` 一码两用（TRADE_ORDER_STATUS_INVALID vs COMMUNITY_REACT_INVALID，common/error_codes.py:81,133）。
- chat SSE `error` 事件已定义但生成器永不发送（chat/router.py:224-273），前端错误分支形同虚设。
- 课程域分页壳 `{items,page_meta}` 与全站 `{total,page,page_size,items}` 不一致（domains/course/schemas.py:21-30）。
- admin 视频分片上传 4 端点为占位 stub（domains/course_admin/router.py:202-228）。

### 2.3 孤儿模块

`app/admin/question_admin/` 整套（router/service/schemas）未被 main.py 挂载，与生效的 `domains/question_admin` 同前缀共存，误 include 即冲突——建议删除或归档。
