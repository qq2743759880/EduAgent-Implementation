# 开发历史

项目从 EduAgent 演进为 Bili-Study，保留原有业务与 RAG 契约。目录改名为 `bili-study-agent`、`bili-study-frontend`，内部兼容标识 `Edu` / `edu-agent` / `EAPI` 不等于旧产品入口。

早期 TASK、设计文档、验收响应及改名前原件保存在维护者本地的项目外归档，带清单、SHA-256 和恢复工具。它们没有作为当前源码发布内容，以免公开凭据、用户数据及过时运行路径。归档没有删除；需要具体历史依据时由维护者按清单回取。

本次 GitHub 更新保留现有仓库提交历史，通过新增提交提供当前源码，不改写旧提交。源码与业务数据备份是不同交付物。
