# AUTO20 更新清单：十四单成果一览（T1-T14 + T13b）

> 生成：2026-09-22（AUTO20 T15 文档同步）。日期均为 2026-09-21~09-22。分支 feature/opt-waves。
> 给非技术读者的说明：下面每一行是一次已验收的功能更新；「用户可见价值」= 你实际能摸到的变化。全部数字来自验收报告实测（AUTO20/reports/），非估算。

## 你能直接感受到的变化（5 件事）

1. **AI 会记住你说的话，而且当场告诉你记住了**——对 AI 说「我叫XX请记住」，回答尾部出现绿色「💾已记住」小条；换个新会话马上问，几秒内就能答对（实测 3.7 秒）。
2. **AI 不再说谎**——如果 AI 声称"已收藏/已创建"但实际没执行，答案尾部会出现黄色警告条明说「未实际执行」。这是诚实护栏，不是故障。
3. **管理员多了「会话审计」页**——只能看、不能改，专供运营/审核巡检；普通用户和经理都打不开。
4. **大视频随便传**——课程管理里点「⬆上传视频」，108MB 大文件断网也能自动重试、续传成功、自动转码、学习页直接播放。
5. **对话能建课（带人工确认）**——管理员在对话里让 AI 建课程，会先弹出确认卡，点确认才真正创建（该确认开关目前默认关闭，功能已就绪待运营开启）。
