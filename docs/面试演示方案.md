# EduAgent 面试演示方案（共享屏幕逐技术点操作脚本）

> 原则：每个技术点=「一句定位 → 现场操作 → 指着屏幕说什么 → 高频追问与答法」。全部演示可在本机 15 分钟内跑完，任何一步的命令与预期输出都写死，避免现场翻车。

## 0. 开场（1 分钟）
共享浏览器 `http://127.0.0.1:3000/login-register.html` + 提前开好的三个标签页：8000/docs、Neo4j Browser、终端（tail -f 日志）。
开场白："这是一个教育平台的 AI 助手系统，我按数据流从头到尾演示：前端→网关→LangGraph 编排→RAG 四通道检索→存储与观测，最后跑一遍工程体检。"

## 1. FastAPI（2 分钟）
- 操作：开 `http://127.0.0.1:8000/docs` → 展开一个接口 → 试调 `/api/series`；再开 `openapi.json` Ctrl+F 搜 `payment-notifications/channel`
- 说辞：210+ 路由、统一响应壳 `{code,message,data}`、错误码集中在 error_codes.py（如 50301=依赖降级）
- 追问「异常处理」：演示 40450（HITL 线程不存在）——接口层抛 AppException，全局兜底转脱敏信封

## 2. Next.js + 双前端（2 分钟）
- 操作：3000 首页 → 登录 → courses → 点 admin 入口进 `/admin/users-refine`（React+Refine+TanStack Query 真实数据分页排序）
- 说辞：双轨迁移策略——静态页保演示稳定，新架构按域渐进迁移；**生产形态判别**：开 DevTools 看 `/_next/static/development/_buildManifest.js` 404=生产 build（已打包 `.next-prod`）
- 追问「为什么两套」：棕地渐进迁移+回滚安全的取舍，迁移完成域走变更单退役

## 3. Milvus 向量库 + 三通道检索（3 分钟，核心）
- 操作①：终端跑 `python scripts/eval/milvus_count_probe.py --rounds 1` → 屏幕出现 count/enumerate/stats 阶梯与分区归属
- 操作②：开 `logs/app.log` 尾部指 `[retrieval-profile] milvus total=…embed(dense)=…sparse=… docs=150`
- 说辞：edu_knowledge 单集合多分区（course_public 公共+user 租户隔离）；**稠密（BGE-M3 CUDA）+稀疏（BM25 词面）双通道召回 150 → RRF 融合 → BGE-reranker 重排 → V2 分位断崖截 5**；internal 标量字段做租户/角色过滤（student 看不到内部文档——可现场对比 student/admin 两 token 的检索结果数）
- 追问「为什么 0.98」：出示三把尺——路由卡尺 0.0781（旧，结构错配）、内容块尺 0.9844、改写问句尺 0.9841（无子串保底）——**分尺测量防自证**

## 4. 重排断崖 V2（1.5 分钟）
- 操作：指日志行 `[retrieval-profile] cliff-v2 quant=0.60 floor=0.341 kept=5/20`；翻 `contracts/rag-baseline-eval64-v2.json` 基线
- 说辞：V1 相对跌幅断崖在归一分上首步系统性误斩（28/64 只剩 2 条）；V2=本轮分数分布分位下限；灰度开关+双跑对账后开启；**上限 final_max_k=5 是冻结契约，我们只优化"5 条里选得更准"**

## 5. GraphRAG 四通道 + Neo4j 知识图谱（3 分钟）
- 操作①：浏览器开 `http://127.0.0.1:8000/api/kg/course/1/path?from=KP-PY-VAR&to=KP-PY-SQL` → 屏显 hops=5 完整路径 + cycle_checked
- 操作②：Neo4j Browser（bolt 192.168.85.101）跑 `MATCH (n) RETURN n LIMIT 50` 看图；跑 `MATCH p=()-[r:PREREQUISITE]->() RETURN p LIMIT 25`
- 说辞：课程/章节/知识点/文档块四类节点，PREREQUISITE 先修图做**学习路径最短路+环检测**（坏数据返回 40910 而非死循环）；Neo4j 断连 → 50301 脱敏降级、主链无感（现场指一次性实例实测记录）
- 追问「为什么还要 Neo4j，MySQL 不行吗」：多跳邻居查询 Cypher 一句 vs MySQL 递归 CTE 性能/可读性；这是真实启用的第四检索通道（graph_expand 灰度位）

## 6. MongoDB（1.5 分钟）
- 操作：Compass 或 mongosh 展示 `learning_event` 集合 + `GET /api/analytics/learning-events/summary?range=7d`（带 admin token）
- 说辞：高频 append-only 学习事件流放 Mongo（写路径旁路异步、失败熔断+积压回灌零丢失实测）、MySQL 仍是事务事实源；**对账脚本** mevent_reconcile 双库一致率 100%
- 追问「为什么不放 MySQL」：写放大隔离 + 灵活 schema；事务一致性需求留在 MySQL

## 7. Redis（2 分钟）
- 操作：`redis-cli -p 6377` 依次：`KEYS rl:*`（限流窗）、`TTL` 某键、`LLEN` 记忆队列、指 HITL resume 决策键
- 说辞：限流（42900 的幕后）、JWT refresh allowlist、checkpoint（LangGraph PlainRedisSaver 双键隔离 anon-/task24-{uid}）、HITL confirm 决策、记忆队列——**五用一体**；防过载槽 TTL 自愈
- 追问「Redis 挂了会怎样」：限流 fail-open+熔断、记忆旁路停写、checkpoint 不可用则流式不可用——分层降级演示日志

## 8. LangGraph + HITL + 工具安全（3 分钟）
- 操作：chat 发「帮我导入一份知识库文档」→ 屏幕出现**确认卡**（pending_confirm 五字段）→ 先「拒绝」→ 再来一次点「确认」→ 工具真执行
- 说辞：流式主链路=LangGraph 九节点图；写类工具四道防线=权限门(default deny)→HITL 中断→确认执行→审计；student 诱导攻击实测零执行
- 追问「怎么防 prompt 注入越权」：权限门按角色×工具矩阵服务端裁决，LLM 意图不参与授权；参数 schema 精确绑定（exact-pin）

## 9. 可观测（2 分钟）
- 操作：`/metrics`（Prometheus 文本格式）+ `logs/app.log` 的 retrieval-profile 六段日志 + `logs/watchdog_8000_events.log`
- 说辞：OTLP 管道已实现（endpoint 未接生产后端故 state=disabled，诚实说明）；8000 看门狗已 Windows 任务计划服务化——现场 `schtasks /query /tn EduAgent-Watchdog`，再现场杀 8000 展示 90 秒自愈
- 追问「为什么不是完整 Prometheus 平台」：exporter 就绪、后端接入属部署期事项（如实说，不吹）

## 10. 工程质量门（压轴 3 分钟）
- 操作：跑 `node scripts/check-demo.mjs` → 21 项全绿滚动输出；再跑 `pytest tests/ -q` 尾行 **1798 passed / 0 failed**
- 说辞：21 项演示体检（Milvus/Redis/Mongo/后端/前端/登录链/关键页/DEBUG 探针/契约对账/向量一致性/HITL 真实性/内部可见性/Redis 对账/lifecycle/MCP 三态/root path/VEC-LOCK/OTLP/数据卫生）+ 三方契约对账（前端调用×后端路由×冻结契约，断点必须=0）+ 1798 自动化测试回归门禁 exit0
- 收尾金句："每一条绿色都对应一个曾经的真实事故——这套体检单是事故驱动长出来的。"

## 高频综合追问备答
- 「数据丢了怎么办」：MySQL binlog+general_log 可溯源；Milvus 可由 MySQL 源文档全量重建；VM 两次事故实测零数据丢失
- 「并发安全吗」：T13 并发盲测 3 次 full-run 零功能性失败；双防污染护栏（限流窗+依赖注入清理）
- 「AI 答错了怎么办」：RAG 有据可引（引用块可溯源 chunk_id）；拒答与降级诚实化（无据可引→明说）
