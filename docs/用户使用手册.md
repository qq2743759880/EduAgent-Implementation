# EduAgent 用户使用手册（含真人体验测试清单）

> 适用版本：2026-09-20（feature/opt-waves @ 8d6e5b8+）。学生端=静态页（3000 端口生产形态）；管理端=同域 admin 页面 + React 精炼版。

## 一、启动流程（按序）

| 步 | 操作 | 验证 |
|---|---|---|
| 1 | 启动 VMware 虚拟机「CentOS 7 64 位」（**注意：不是"的克隆 docker"那台**），等 1-2 分钟让 docker 容器自启 | 探 192.168.85.101:19530 通 |
| 2 | Redis 容器（Docker Desktop 里 `prisma-ai-redis-container-1`，一般自启）| 探 127.0.0.1:6377 通 |
| 3 | 后端：`edu-agent/` 下 `powershell` 执行 `Start-Process -FilePath '.\.venv\Scripts\python.exe' -ArgumentList '-m uvicorn app.main:app --port 8000' -WindowStyle Hidden`（看门狗服务化后杀掉会自动拉起）| http://127.0.0.1:8000/health → {"status":"ok"} |
| 4 | 前端（生产形态）：`edu-frontend/` 下 `set NEXT_PROD_DIST_DIR=.next-prod&& node node_modules/next/dist/bin/next start -p 3000` | http://127.0.0.1:3000/login-register.html → 200 |
| 5 | **体检**：`edu-agent/` 下 `node scripts/check-demo.mjs` | 汇总「绿 21/21……演示环境就绪」 |
| 6 | 前端已打包（`.next-prod/` 已构建）。改了前端代码才需要重新 `next build`；平时直接 start | 探 `/_next/static/development/_buildManifest.js` = 404 即生产形态 |

环境变量 `.env` 关键项：`DEBUG=true`（**仅限本机**；对外部署必须 false）、`REDIS_PORT=6377`、`LLM_*`（STRONG=deepseek-flash 主力 / FAST=ark-code-latest 备用）。

## 二、学生端功能与操作（http://127.0.0.1:3000）

### 1. 注册/登录（login-register.html）
- 注册：填用户名/密码/昵称 → 注册成功自动登录（W1-C4）
- 登录：账号+密码 → 跳转首页；admin/manager 角色会看到管理入口
- 未登录访问受保护页 → 自动跳登录页

### 2. 课程列表（courses.html）
- 首屏从 `/api/series` 加载真实课程系列（卡片：名称/系列码/标签）
- 鼠标：点卡片 → 进课程详情；顶部搜索框过滤

### 3. 课程详情（course-detail.html?id=…）
- 展示系列→章→节三级结构与课时列表
- 操作：点「开始学习/继续学习」→ 进入 learning 页；收藏按钮（登录态）；课件入口（部分显示"后续上线"占位=诚实降级）

### 4. 学习页（learning.html?id=…）
- 视频播放：视频进度心跳自动上报（断点续播——重进自动定位上次进度）
- 图文课时直接渲染；完成课时自动打卡（XP/徽章体系联动）
- 右侧/下方：该课关联练习入口

### 5. 练习（practice.html）
- 选择题作答 → 提交判分 → 错题进错题本；答题事件异步入库
- 绑定课程的练习从课程详情进入（bindQuestion 已修）

### 6. 社区（community.html）
- 发帖/回帖/点赞；置顶帖排序在首页；分页无重复（P.id DESC 全序化）

### 7. 我的（me.html）
- 资料修改（昵称/头像——走 `PUT /api/users/me/profile`）
- 我的课程/收藏/订单/优惠券入口；XP 等级与徽章展示

### 8. 购买流程（course-detail → 下单）
- 点「购买」→ 创建订单（需 Idempotency-Key，前端已封装）→ 支付页（mock 渠道）→ 支付回调 → 报名生效
- 退款走订单详情「申请退款」（pending 态可退）

### 9. 优惠券/收藏/错题本（favorites.html / coupons.html / me 页签）
- 领券（重复领券=幂等提示不报错）、下单选券抵扣；收藏夹管理；错题重练

## 三、管理端功能与操作

### admin-dashboard.html
- 指标卡：用户规模/活跃/增长/角色分布（真实聚合）；订单/营收/热门课程榜=「暂未开放」占位（后端聚合端点未建，诚实降级）

### admin-users.html（用户管理）+ /admin/users-refine（Refine 精炼版）
- 列表/搜索/筛选；改角色（admin/manager/student/teacher）；封禁/解封
- 用户学习情况弹窗：内容块为「缺口占位」（后端无该聚合端点——诚实占位不发死请求）
- **Refine 版**（推荐演示）：分页/排序/筛选全真实数据 + 403 错误信封可见

### admin-courses.html + 回收站（admin-courses-recycle-proto.html）
- 课程/模块/课时管理；删除进回收站（软删）；force 删除仅 ADMIN

### admin-questions.html（题库管理）
- 题库列表 → 题目 CRUD（真实路由 /api/admin/questions/questions...）；按 bank 管理

### admin-mcp.html
- MCP 工具健康扫描（异步：提交→轮询→结果）；工具列表与三态（ok/virtual/broken）

### admin-rag-upload.html
- 知识库文档上传（走 object_key 三段命名防覆盖）；导入后可在检索中被引用
- **student 上传的文档只有本人和管理员可见**（internal 隔离）

### admin-rag 页（collections）
- 集合管理卡片（部分功能走「占位」诚实降级）

## 四、AI 助手（chat）使用
- 入口：导航 AI 助手（chat.html）→ 流式回答（首字 ~2-3s）
- 会问：课程内容/概念解释/学习路径；引用来源带 doc 引用
- 高风险操作（如知识导入）：触发**确认卡**（pending_confirm）→ 点「确认」才执行/「拒绝」取消；超时自动拒绝
- 记忆：对话中的偏好会被记忆（下一轮生效，可在「我的」看到记忆效果）
