## 二、学生端功能与操作（http://127.0.0.1:3322）

### 1. 注册/登录（login-register.html）
- 注册：填用户名/密码/昵称 → 注册成功自动登录（W1-C4）
- 登录：账号+密码 → 跳转首页；admin/manager 角色会看到管理入口
- 未登录访问受保护页 → 自动跳登录页

### 2. 课程列表（courses.html）
- 首屏从 `/api/series` 加载真实课程系列（卡片：名称/系列码/标签）
- 鼠标：点卡片 → 进课程详情；顶部搜索框过滤

### 3. 课程详情（course-detail.html?id=…）
- 展示系列→章→节三级结构与课时列表
- 操作：点「开始学习/继续学习」→ 进入 learning 页；收藏按钮（登录态）；课件入口（部分显示"后续上线"占位=诚实降级）

### 4. 学习页（learning.html?id=…）
- 视频播放：视频进度心跳自动上报（断点续播——重进自动定位上次进度）
- 图文课时直接渲染；完成课时自动打卡（XP/徽章体系联动）
- 右侧/下方：该课关联练习入口

### 5. 练习（practice.html）
- 选择题作答 → 提交判分 → 错题进错题本；答题事件异步入库
- 绑定课程的练习从课程详情进入（bindQuestion 已修）

### 6. 社区（community.html）
- 发帖/回帖/点赞；置顶帖排序在首页；分页无重复（P.id DESC 全序化）

### 7. 我的（me.html）
- 资料修改（昵称/头像——走 `PUT /api/users/me/profile`）
- 我的课程/收藏/订单/优惠券入口；XP 等级与徽章展示

### 8. 购买流程（course-detail → 下单）
- 点「购买」→ 创建订单（需 Idempotency-Key，前端已封装）→ 支付页（mock 渠道）→ 支付回调 → 报名生效
- 退款走订单详情「申请退款」（pending 态可退）

### 9. 优惠券/收藏/错题本（favorites.html / coupons.html / me 页签）
- 领券（重复领券=幂等提示不报错）、下单选券抵扣；收藏夹管理；错题重练

## 三、管理端功能与操作

### admin-dashboard.html
- 指标卡：用户规模/活跃/增长/角色分布（真实聚合）；订单/营收/热门课程榜=「暂未开放」占位（后端聚合端点未建，诚实降级）

### admin-users.html（用户管理）+ /admin/users-refine（Refine 精炼版）
- 列表/搜索/筛选；改角色（admin/manager/student/teacher）；封禁/解封
- 用户学习情况弹窗：内容块为「缺口占位」（后端无该聚合端点——诚实占位不发死请求）
- **Refine 版**（推荐演示）：分页/排序/筛选全真实数据 + 403 错误信封可见

### admin-courses.html + 课程详情 + 视频上传 + 回收站
- `admin-courses.html`：课程/模块/课时管理；删除进回收站（软删）；force 删除仅 ADMIN
- `admin-course-detail.html`（点课程进入）：班次/课次行内「⬆ 上传视频」按钮 → 分片上传面板（自动 5MB 分片：init-chunked → 逐片 PUT → finalize → 绑定课次）→ 转码状态徽章轮询（待处理/转码中/转码完成/转码失败）→ 完成后学习页可播。**支持大文件**：单个分片失败自动重发 2 次；整体失败出现「↻ 重试上传」按钮（保留原文件整链重传）。实测验收：108.8MB / 22 分片在人为断网注入下自动重试→错误态→解除后重传成功，114,069,910 字节落盘可播（AUTO20 T4，commit e4dad35）
- `admin-courses-recycle-proto.html`（回收站）：已全量接线真实接口——已下架（软删）系列列表；「恢复」走确认弹窗（恢复后置为草稿态）；「彻底删除」两步确认（红色危险弹窗 + 输入系列编码完全一致才可执行；物理真删仅管理员且零引用校验，仍存在班次等关联记录会被拒绝）

### admin-chat-audit.html（会话审计）— 2026-09-22 新增（AUTO20 T5，commit 4aa7bff）
- **admin 专属只读视图**：服务端 `require_role([ADMIN])` 硬校验（实测 admin 316 会话正常；student 直连端点 403 + 页面守卫跳转）
- 页顶「审计用途（只读）」横幅：可查看学员会话列表与消息内容，**无任何修改/删除能力**
- 操作：会话列表分页 + 按 user_id 过滤 → 点会话打开「历史抽屉」查看消息明细（角色/内容/时间）
- 入口：8 个 admin 页导航均有「会话审计」链接

### admin-questions.html（题库管理）
- 题库列表 → 题目 CRUD（真实路由 /api/admin/questions/questions...）；按 bank 管理

### admin-mcp.html
- MCP 工具健康扫描（异步：提交→轮询→结果）；工具列表与三态（ok/virtual/broken）

### admin-rag-upload.html（RAG 控制台，五 tab 全接线 — FEAT-WIRE-V2 #4）
- 知识库文档上传（走 object_key 三段命名防覆盖）；导入后可在检索中被引用
- **student 上传的文档只有本人和管理员可见**（internal 隔离）
- 顶部五个 tab 全部可用（旧版仅「上传」有面板，其余为死按钮，已修）：
  - **集合**：集合列表 + 分区查看/删除 + 重建
  - **上传**：拖拽/多选 → 前端预校验（扩展名白名单、≤200MB、≤50 个）→ 导入任务每 5s 轮询 pending→running→succeeded/failed（含 chunks 进度与错误明细）
  - **调参**：检索参数预设（GET/POST /api/admin/rag/presets）
  - **审计日志**：GET /api/admin/rag/audit-log 倒序分页（角色/query/召回与最终条数/模型/延迟/降级/流式）
  - **高级检索**：POST /api/admin/rag/search 管理员全库检索（top_k/final_max_k/预设可选）

## 四、AI 助手（chat）使用
- 入口：导航 AI 助手（chat.html）→ 流式回答（首字 ~2-3s）
- 会问：课程内容/概念解释/学习路径；引用来源带 doc 引用
- 高风险操作（如知识导入）：触发**确认卡**（pending_confirm）→ 点「确认」才执行/「拒绝」取消；超时自动拒绝
- 记忆：对话中的偏好会被记忆（下一轮生效，可在「我的」看到记忆效果）
- **记忆反馈条**（AUTO20 T2，commit a74ea59）：对 AI 说「我叫XX，请记住」（或其他偏好）→ 本轮回答结束（done 帧）时 AI 气泡尾部出现绿色「💾已记住：…」小条；落库是同步的（done 帧前完成），**换一个新会话立刻提问，5 秒内就能答对**（实测 A 会话自述新名字 → B 会话 3.7s 内答对，AUTO20 T1，commit 22169b9）。没出现绿条=该条没被记忆落库
- **工具回执警示条**（AUTO20 T7，commit d2b6efa）：如果 AI 答案里声称做了写类操作（收藏/导入/创建/删除/支付等）但工具实际**没有**真实执行（无 success 凭据），答案尾部会出现黄色条「⚠️ 上述工具操作未实际执行，请以工具调用记录为准。」——**这是诚实护栏，不是故障**：说明那个操作确实没执行（例如被权限拦截）。正常真实执行时不会出现（AUTO20 T8 透传凭据后护栏零误标，commit cf67bbc）
- **对话建课工具 course_create**（AUTO20 T12，commit e7d7176）：admin 在对话里说「帮我创建一门新课，标题'XX'，系列码 xx_001」→ 若开启 HITL 会弹出**确认卡**（工具名+参数+风险级 high+确认/拒绝+300s 超时）→ 点「确认」后才真正落库（拒绝/超时=零数据变更）。⚠️ 如实说明：本演示环境 `edu-agent/.env` 已显式 `HITL_ENABLED=True`（TA2 修复粘连行后开关生效，demo 默认开）；**生产可经 `.env` 关闭**（改 `False` 恢复默认关闭、零行为变化）；权限矩阵 admin=allow、manager/student/teacher=deny（student 诱导实测连确认卡都看不到，直接拒绝）

### HITL 确认卡演示（AUTO20 T12 / TA2，对话建课人工确认）
> 开关现状：本演示环境 `edu-agent/.env` 已显式 `HITL_ENABLED=True`（owner 裁定 demo 默认开）。**生产环境可经 `.env` 关闭**——把 `HITL_ENABLED` 改为 `False` 即恢复默认关闭（零行为变化）。

触发话术（admin 在 AI 助手对话框原句）：
```
帮我创建一门课程，标题"TA2演示课程A"，系列码 ta2_demo_a
```
- 必须同时含「创建/建课」类词 + 课程标题（引号包裹）+ 系列码（小写字母数字下划线），三者同现才弹卡；只聊「怎么建课」不会误触发。

两条路现象：
- **approve（同意）**：对话先返回一张**确认卡**（pending_confirm 帧，含 工具名 course_create + 参数 title/series_code + 风险级 high + 确认/拒绝按钮 + 300s 超时），**不直接建课**；点「确认」后系统才真正落库——课程系列表 `series` 新增一行（created_by=当前 admin），对话回执带 `course_create` success 凭据。
- **reject（拒绝）**：同样先弹确认卡；点「拒绝」→ 零数据变更，课程系列表不新增任何行，对话仅有正常回答、无写类执行痕迹（黄色「未实际执行」警示条也不会出现，因为根本没尝试执行）。

超时（300s 未确认）自动按拒绝处理，零数据变更。
