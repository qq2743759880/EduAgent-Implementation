# 可复现的实机演示

## PDF → RAG → 学生问答

2026-10-07，在 DEBUG=false 的现有本地环境中，管理员通过原 RAG 上传页真实提交了仓库提供的 [缓存课堂 PDF](../bili-study-frontend/public/samples/bili-study-cache-lab-20261007.pdf)。这是项目自编的课堂演示材料，Orchid Protocol 是示例名称，不是行业标准。

MinerU 4.0.10 解析出 1 页、8 个 block；既有 IR / IngestWorker 加载 3 个 Milvus chunk，并形成 Neo4j 关联。学生通过原 Chat 询问课堂 TTL、一致性与 single-flight，得到带文档来源的答案：练习参数为 **37 秒**。37 秒是材料中任意设定的练习值，不是缓存最佳实践指标。

![实际学生问答页面](../assets/student-answer.png)

操作路径：管理员 → RAG 知识库 → 上传 PDF → 自动 MinerU → 查看处理状态 / 解析与图谱 / 本次 Trace；学生 → AI 学习问答 → 提问上面的课堂内容。业务数据和测试账号不包含在源码中，需要在自己的已配置实例上传样例。

本次普通知识问答产生真实 LangGraph 九节点及检索、模型调用 spans。六个核心节点复用 SixNodeHarness。课程 Tutor 则走 StudyContext 分支。管理端「基础设施 / 技术演示」可打开配置的 Neo4j Browser 和 Jaeger；请选择本次任务链接，Jaeger 的内存存储重启后可能丢失旧 Trace。

修复记录：原文虽已被召回，旧知识快路径将每段裁至 120 字符，遗漏文档后面的答案。现在复用既有受预算约束的原文格式化，重复同一问题后正确引用 37 秒。架构图只能解释职责，这一真实输入与答案验证了数据链。

## 视频课程

管理员 → 课程详情 → 班次 / 模块 / 课次 → 视频区域 → 输入有权使用的 Bilibili 链接或上传本地视频 → 生成资料 → 查看各阶段。学生正常报名后进入学习页，播放、打开笔记 / 字幕 / 导图，点击章节与引用跳转，并用「本课答疑」问视频内容。

已实测的来源包括 LeetCode P1 / P3 / P26，以及 Python、Agent 记忆与 RAG 视频。平台权限或网络失败会显示真实失败；不保证任意链接都能获取。当前目录中的历史课程不等于全部已验收课程。
