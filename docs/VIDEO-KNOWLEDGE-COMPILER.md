# 视频知识能力

管理员在现有课程详情页创建模块和课次，展开课次视频区域。本地上传、授权已绑定视频、Bilibili 链接复用 `/api/admin/video-knowledge/tasks`。明确重新生成产生新版本，普通重复提交保持幂等。

## 管理员操作

1. 课程管理 → 课程详情 → 选择班次 → 模块 / 课次 → 视频区域。
2. 上传可播放的视频，或选择已绑定视频，或输入 Bilibili 链接与分 P。
3. 点击「生成 AI 学习资料」，页面显示真实阶段、更新时间与失败原因，并自动刷新。
4. 成功后按当前版本自动授权、发布并接入现有 RAG；历史人工预览 / 驳回 / 批准 API 保留，携带版本身份。
5. 区分「资料已发布」与「RAG 已就绪」。只有 READY 才提供学生正式资料；失败阶段可重试，原视频不受影响。

原生字幕优先，可自动 ASR。编译输出 Summary、AI Note、章节、带时间戳字幕和思维导图；课程相关练习由正式资料生产链绑定到课次，学生通过学习页与题库入口练习。思维导图是可展开的树状结构，界面不承诺桌面脑图编辑器。

## 学生操作

学生使用自己的账号免费报名 → 学习页播放 → 查看 AI 笔记 / 字幕 / 导图 → 点章节或引用跳转 → 本课答疑。服务端校验报名、课程、课次、视频与正式版本，标题背景不能代替正式检索证据。

## 已验证范围与边界

已实测 LeetCode 源 P1 / P3 原生字幕与 P26 显式 ASR，以及 Python、Agent 记忆、RAG 来源的页面导入、自动生产、发布和学生问答。本地视频上传与已有视频重编也已有验收。它们不代表每门历史课程都有真实视频或习题。

新版本进入向量库但 publication 仍 pending 时不得成为学生证据；已有 READY 版本继续提供。转写、图谱、资料 API 或 RAG 故障不得禁用播放器。

Bilibili 获取依赖平台权限与网络，有时需要用户自己的 Cookie。平台拒绝时真实报告失败，不绕过来源限制，可使用有权使用的本地视频。Cookie、视频和模型权重不包含在源码发布中。
