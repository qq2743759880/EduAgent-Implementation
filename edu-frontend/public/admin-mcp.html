这个页面是什么
把外部 MCP Server（工具提供方）注册进来，让 AI 在对话中调用它们的工具。 本页负责四件事：注册 Server、扫描/检查健康、发现并测试工具、查看调用日志。
看 MCP Server 表的「健康」列：全部 OK 说明工具可被 AI 调用；出现 ERR 就到「上次错误」看原因。
三步上手
  1. 点「+ 新增 Server」，按步骤条填连接信息并保存；
  2. 保存后回到列表点该行的「健康」；绿色通过再点「发现工具」；
  3. 到「工具清单」点「测试」用一段 JSON 参数试跑，右侧「调用日志」留下记录即接入成功。
不确定填什么？弹窗步骤 2 里 stdio 适合本地脚本，sse / http 适合远端服务。
四块区域各管什么
① MCP Server 注册与启停（每台一行）· ② 工具清单 已发现的工具与在线测试 · ③ 调用日志 每次调用的状态/耗时/trace_id。
想知道 AI 到底能不能用某个工具？看「工具清单」的健康徽标是否 健康。
已接入真实 MCP 管理端：Server 注册与管理、 健康扫描（同步全量扫描，Server 多时耗时较长，按钮会显示扫描中）、 工具清单与在线测试、调用审计，并支持单 Server 健康检查 / 发现工具 / 注销。

新增 MCP Server

  1. 1 填 code / 名称
  2. 2 选传输协议
  3. 3 填连接参数
  4. 4 健康检查
  5. 5 保存

给这台 Server 起个内部标识。server_code 是唯一键，创建后不建议再改；显示名称只是给人看的。

示例：local-tools + 显示名「本地工具集」。这一步只填标识，连接方式在下一步选。

选它怎么连。本地脚本走 stdio；远端服务走 sse / http（区别在 URL 结尾是否有 /sse）。

不确定选哪个？本机 Python/Node 脚本 → stdio；已部署成网址的服务 → sse（地址含 /sse）或 http。

填连接与超时。下面只显示当前传输方式需要的字段，切换传输会自动换。

stdio：命令填可执行程序（如 python），参数填 JSON 数组。默认超时 5000/30000 一般够用，远端慢服务可调大。

先试连再保存。点下面按钮会临时用当前填写的连接参数做一次连通性探测；通过再保存，能避免"存进去才发现连不上"。

探测失败不影响保存（例：服务尚未启动）。也可先「跳过，直接保存」，保存后在列表用行内「健康」按钮复查。
