高数第三章「分部积分」易错题集锦

小豆芽·2026-08-20 09:12 ·👁 1283 ·👍 343 ·⭐ 58 ·💬 18
🎉 +2 积分

整理了分部积分的 5 个典型易错点，每个都配了注释和反例，评论区欢迎补充你的踩坑经历。

1. 分部积分公式方向

公式：∫u dv = uv − ∫v du。易错点是 u 与 dv 选反，导致越积越复杂。

口诀：反对幂指三，先选 u 后选 dv。

2. 循环积分陷阱

遇到 ∫eˣ sinx dx 这类会回到原式的积分，需要移项合并，别死磕到底：

# 伪代码示例
I = ∫ eˣ sinx dx
I = eˣ sinx − ∫ eˣ cosx dx
I = eˣ sinx − (eˣ cosx + I)
2I = eˣ (sinx − cosx) + C
