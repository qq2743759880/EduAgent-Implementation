层实现与职责
页面与业务Next.js / React 与现有静态页面；FastAPI 提供鉴权、课程、学习、生产任务与 SSE 问答；MySQL 保存业务和正式发布权威。

AgentLangGraph 控制流程，SixNodeHarness 实现核心节点；MCP 工具、上下文整理、压缩、缓存、个人记忆与 HITL / checkpoint 有各自服务边界。
运行与数据Redis 承载任务协调、队列、锁和上下文；MinIO 保存资产；MongoDB 承载事件；OpenTelemetry / Jaeger 展示执行 Trace，Prometheus 与日志辅助诊断。
