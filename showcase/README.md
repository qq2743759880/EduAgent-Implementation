# Bili-Study 项目展示

打开 `index.html` 查看架构、技术栈、真实运行截图与 25 个页面预览。页面 HTML 可下载后本地打开，也可在仓库根目录运行 `python -m http.server 18010`，访问 `http://127.0.0.1:18010/showcase/index.html`。

`standalone` 使用匿名化接口快照。登录、写操作与问答仅回放，不连接真实后端；不包含原始视频或在线模型。历史资料不存在和处理失败状态保留，不用演示成功覆盖事实。

README 中直接展示静态画廊；进一步体验才需要打开 HTML。截图中的旧 EduAgent 标识保留当时开发状态，不影响当前产品名称 Bili-Study。
