第 3 题单选· 编程
下列哪段 Python 代码能正确实现“遍历列表元素并输出索引”？
✓
回答正确！+1 金豆
本知识点已加入复习队列 · 数据上报 progress 契约⑤
✦本题解析 · analysis_text（Markdown 预览，与 task59 管理端一致）
枚举遍历enumerate索引访问

解题思路

  • enumerate() 同时返回「索引 + 元素」，是遍历"带索引"的标准写法。
  • A 仅打印索引不打印元素；B 对元素取 len() 语义错误；D 中 list 没有 enumerate() 链式方法。
  • 答案选 C，其输出为 0 1 2 … n-1。
# 推荐写法 nums = ["a", "b", "c"] for i, v in enumerate(nums): print(i, v)
💡
易错点：若只需索引用 range(len())；若同时要元素与索引务必用 enumerate，避免两次遍历。

第 9 题判断· 数据结构
Python 的 tuple（元组） 与 list（列表） 一样，创建后都可以修改元素。

不可变tuple

  • list 可变（可增删改元素）；tuple 不可变（不可修改创建后的元素）。
